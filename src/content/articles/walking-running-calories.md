「30分歩いたら何kcal減るんだろう」——これは計算できます。しかも、推測を使わずに。

## メッツという物差し

**メッツ（METs）**は、その活動が「安静時の何倍のエネルギーを使うか」を表す数字です。じっと座っているのが1メッツ、普通に歩くのが3メッツ、なら歩くのは座っているときの3倍、ということになります。

消費カロリーは次の式で求まります。

> **消費カロリー(kcal) = メッツ × 時間(時) × 体重(kg) × 1.05**

体重が式に入っているのが大事なところです。**同じ30分歩いても、体重が重い人のほうが多く消費します。** 運んでいる体そのものが重いからです。

メッツの値は厚生労働省「健康づくりのための身体活動基準2013」の表と、その元になった Ainsworth ら (2011) のデータベースに載っているものです。当サイトでは**この表にある値だけを使い、載っていない活動は「データなし」として扱っています。**

## 歩く・走るのメッツ値

| 活動 | メッツ | 出典の表での説明 |
|---|---|---|
| 普通に歩く | 3.0 | 平地・分速67m（犬を連れてなど） |
| 平地を歩く | 3.5 | 平地・やや速め |
| 速歩 | 4.0 | やや速歩・階段をゆっくり上る |
| ゆっくりジョギング | 6.0 | ゆっくりとしたジョギング |
| ランニング | 8.3 | 分速134m |

## 体重60kgの人が消費するカロリー

| 活動 | 30分 | 60分 |
|---|---|---|
| 普通に歩く | 95 kcal | 189 kcal |
| 平地を歩く | 110 kcal | 221 kcal |
| 速歩 | 126 kcal | 252 kcal |
| ゆっくりジョギング | 189 kcal | 378 kcal |
| ランニング | 261 kcal | 523 kcal |

**体重70kgなら**、普通に歩く30分で110kcal、速歩30分で147kcal、ランニング30分で305kcalです。体重に比例して増えます。

## 食べ物に置き換えると

数字だけではピンと来ないので、食品成分表の値で換算します。

| 食べ物 | 1食ぶん | カロリー |
|---|---|---|
| ごはん 茶碗1杯（150g） | | 234 kcal |
| おにぎり 1個（110g） | | 187 kcal |
| 食パン 6枚切り1枚（60g） | | 149 kcal |
| バナナ 1本（100g） | | 93 kcal |
| ビール 350ml缶 1本 | | 137 kcal |
| 板チョコ 1枚（50g） | | 275 kcal |
| ポテトチップス 1袋（60g） | | 325 kcal |

カロリーは成分表の収載値どおりです。**「1食ぶんを何gとみなしたか」は当サイトの決めごとなので、必ず併記しています。**

並べるとこうなります（体重60kgの場合）。

- **普通に歩く30分（95kcal）** ≒ バナナ1本
- **速歩30分（126kcal）** ≒ ビール350ml缶1本
- **ランニング30分（261kcal）** ≒ ごはん茶碗1杯強
- **ポテトチップス1袋（325kcal）** を消費するには、速歩で**77分**

## 正直に言うと、運動だけで痩せるのは効率が悪い

脂肪1kgはおよそ7,200kcalです。体重60kgの人が**速歩だけ**でこれを消費しようとすると、**約29時間**歩く計算になります。毎日1時間歩いても1か月近くかかります。

**これは「歩いても意味がない」という話ではありません。** 事実として、食事のほうが動かしやすい変数だ、というだけです。ポテトチップス1袋を食べないほうが、77分歩くよりずっと簡単です。

一方で、運動には別の価値があります。

- 減量中でも筋肉量を保ちやすくなる（[プロテインの記事](/articles/protein-intake-basics)も参照）
- 続けやすい生活習慣として定着しやすい
- 「今日これだけ動いた」という記録が、続ける動機になる

**食事で作った差を、運動が補強してくれる。** この順番で考えるとうまくいきます。

## 歩数から考えるときの注意

「1万歩で◯kcal」という数字をよく見かけますが、**歩数だけでは消費カロリーは決まりません。** 歩幅・速度・体重・地形でまったく変わるからです。

当サイトでは、歩数から直接カロリーを出すことはせず、**「どの速さで何分歩いたか」で計算します。** 推測を挟まないためです。

## まとめ

- 消費カロリー = メッツ × 時間 × 体重 × 1.05
- 体重60kgなら、速歩30分で126kcal、ランニング30分で261kcal
- 速歩30分 ≒ ビール350ml缶1本ぶん
- 脂肪1kg（7,200kcal）を速歩だけで消費するなら約29時間
- 運動は食事で作った差を補強するもの。両方を見るほうが早い

数字はいずれも計算上の目安です。実際の消費量は個人差・環境差で変わります。
