# 食品データについて

`src/lib/foodData.ts` の300食品は、すべて下記から機械的に転記したものです。
**AIによる推測値・補完値は一切含みません。**

## 出典

- 文部科学省「日本食品標準成分表（八訂）増補2023年」第2章（データ）本表
- https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html
- 元ファイル: `20260327-mxt_kagsei-mext-000029402_02.xlsx`（Excel / 約1.9MB / 全2,538食品）
- 数値はすべて **可食部100gあたり**

各食品は成分表の **食品番号** を `id` に、**収載名** を `officialName` に持っています。
アプリ上でも食品詳細に出典と食品番号を表示しており、元データまで遡れます。

## 成分表の記号の扱い

| 成分表の表記 | 意味 | データ上の扱い |
|---|---|---|
| `-` | 未測定 | `null` |
| `Tr` | 微量（最小記載量未満） | `0` |
| `(12.3)` | 推定値・借用値 | `12.3`。`estimated` に項目名を記録し、UIに「推定」バッジを出す |
| 空欄 | 該当なし | `null` |

## エネルギーをPFCから再計算してはいけない

八訂ではエネルギーの算出方法が組成成分ベースに変わり、成分ごとに異なる係数を使っています
（食物繊維は約2kcal/g、アルコールは7kcal/g など）。
このため **P×4 + F×9 + C×4 では収載値と一致しません**。300食品中34件で25%以上ずれます。

| 食品 | 収載値 | 4/9/4で計算 |
|---|---:|---:|
| ひじき（乾） | 180kcal | 299kcal |
| しいたけ（生） | 25kcal | 41kcal |
| 清酒（普通酒） | 107kcal | 21kcal |

`scaleFood()` はカロリーを再計算せず、収載値をグラム数に比例させるだけです。
この挙動は `src/test/foods.test.ts` で固定しています。

## 絵文字

`emoji` は `string | null` です。該当する絵文字が存在しない食品（豆腐・こんにゃく・しょうゆ・
のり など61件）は `null` にしてあり、UI側は絵文字なしで表示します。
このとき名前の左端がずれないよう、`.food__emoji` は空でも幅を確保します。

「近いけれど別の食品」の絵文字は当てません（例: カリフラワーに🥦は使わない）。

## データの検証

`src/test/foods-source.json` は元Excelから抽出した値をそのまま保持しています。
`src/test/foods.test.ts` が全300食品 × 6成分をこのファイルと突き合わせるため、
`foodData.ts` を手で書き換えると、どの食品のどの項目がずれたかを名指しでテストが落とします。

```bash
npm test
```

## 再生成の手順

成分表が更新されたとき、または収録食品を入れ替えたいときの手順です。
Python 3 と `openpyxl` が必要です。

```bash
pip install openpyxl
```

1. 上記URLから第2章（データ）のExcelを `scripts/food-data/seibunhyo2023.xlsx` として保存する
2. `scripts/food-data/` で以下を順に実行する

```bash
python extract.py    # Excel -> all_foods.json（全2,538食品）
python build.py      # 選定・表示名・絵文字 -> selected_foods.json
python emit_ts.py    # -> src/lib/foodData.ts と src/test/foods-source.json
```

3. `npm test` で全件通ることを確認する

収録食品を変えるときは `selection.py` の食品番号リストを、
表示名・絵文字を変えるときは `build.py` の `DISPLAY_NAME` / `EMOJI_RULES` / `EMOJI_OVERRIDE` を編集します。

`build.py` は表示名が未設定の食品番号があるとエラーで止まります。番号を足したら表示名も必ず足してください。

### 絵文字ルールの落とし穴

キーワードで自動付与しているため、部分一致で誤爆します。実際に踏んだものを残しておきます。

- `もも` が「牛もも」「鶏もも」に一致して🍑になった → 行頭に固定（`^もも（`）
- `^鶏` が「鶏卵」に、`^牛` が「牛乳」に一致した → 卵・乳のルールを肉より先に置いた
- 「マヨネーズ（全卵型）」が`卵`に、「大豆もやし」が`大豆`に一致した → `EMOJI_OVERRIDE` で個別に打ち消し

追加・変更したら、`foods.test.ts` の「紛らわしい名前でも正しい絵文字が付いている」を確認してください。
