# 食事摂取基準の参照方針

## 一次資料

- 厚生労働省「日本人の食事摂取基準（2025年版）策定検討会報告書」
- 厚生労働省「食事による栄養摂取量の基準」（令和6年厚生労働省告示第339号による全改）

実装値は告示の別表から転記し、`src/lib/nutritionReference.ts` に一元化する。更新時は公式の告示・報告書・正誤表を確認し、非公式サイトの数値は使わない。

## UIの扱い

- RDAがある栄養素はRDAを「今日の目安」に使う。
- RDAがない栄養素はAIを使う。
- DGは下限・上限の方向を保持する。食物繊維・カリウムは下限、食塩相当量は上限として表示する。
- ULは「摂るべき目標」には使わない。通常食品とサプリメントで意味が異なるものもあるため、Todayの警告には流用しない。
- 1日の表示は栄養状態や欠乏を診断するものではない。

## 未対応条件

妊娠・授乳・月経など、現在のプロフィールで判断できない条件は単一の目安を採用しない。現時点では女性の鉄を `unresolved` とし、摂取量は見せても達成率・不足表示・食品推薦には使用しない。
