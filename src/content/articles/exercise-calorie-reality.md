「今日は30分歩いたから、少しくらい食べても大丈夫だろう」

この感覚がどれくらい合っているかを、数字で確かめてみます。運動をやめた方がいいという話ではありません。**期待していた量と実際の量がずれていると、続かない**からです。

## メッツという単位

運動の強さは**メッツ**という単位で表されます。じっと座っている状態を1として、その何倍のエネルギーを使うかを示したものです。

厚生労働省の「健康づくりのための身体活動基準2013」には、活動ごとのメッツ値が一覧になっています。抜粋するとこうです。

| 活動 | メッツ |
|---|---|
| 立っている（会話・読書など） | 2.0 |
| 普通に歩く（平地・分速67m） | 3.0 |
| 掃除機をかける | 3.0 |
| 床を掃く・モップがけ | 3.3 |
| 速歩・階段をゆっくり上る | 4.0 |
| ゆっくりジョギング | 6.0 |
| エアロビクス | 7.0 |
| ランニング（分速134m） | 8.3 |
| 水泳（クロール・分速46m未満） | 8.3 |

消費カロリーは次の式で求めます。

```
消費カロリー(kcal) ＝ メッツ × 時間(時) × 体重(kg) × 1.05
```

体重が式に入っているとおり、**同じ運動でも体重が重い人ほど消費は大きく**なります。

## 実際に計算してみる

体重70kgの人が速歩（4.0メッツ）を30分した場合。

```
4.0 × 0.5時間 × 70kg × 1.05 ＝ 147 kcal
```

**147kcal**です。ここで食べ物に置き換えてみます。カロリーは食品成分表の収載値です。

| 食べ物 | カロリー | 速歩30分で |
|---|---|---|
| ごはん 茶碗1杯（150g） | 234 kcal | 0.6杯ぶん |
| 食パン 6枚切り1枚（60g） | 149 kcal | ほぼ1枚ぶん |
| おにぎり 1個（110g） | 187 kcal | 0.8個ぶん |
| バナナ 1本（100g） | 93 kcal | 1.6本ぶん |
| 板チョコ 1枚（50g） | 275 kcal | 0.5枚ぶん |

**30分歩いても、ごはん茶碗1杯には届きません。**

逆から見ると、こうなります。ごはん茶碗1杯（234kcal）を消費するのにかかる時間です。

| 活動 | かかる時間 |
|---|---|
| 普通に歩く | 1時間4分 |
| 速歩 | 48分 |
| ゆっくりジョギング | 32分 |
| ランニング | 23分 |

同じ計算を自分の体重で試すなら[運動の消費カロリー](/tools/burn)が使えます。

## この式が示していないこと

数字を受け取る前に、いくつか断っておくべき点があります。

**この式で出るのは、安静時のぶんを含んだ総消費量です。** 「その運動で余分に使った量」ではありません。歩かなくても、その30分ぶんの基礎代謝は使っています。厳密に「運動で上乗せされた分」を知りたければ、その分を差し引く必要があります。

**個人差があります。** 同じ速さで歩いても、体力・フォーム・気温・地面の状態で消費は変わります。表の値は平均的な目安です。

**表に無い活動は分かりません。** 当サイトでは、一覧に無い活動を「近い値」で埋めることはしていません。分からないものは分からないままにしています。

## それでも運動する理由

ここまで読むと運動が無駄に思えるかもしれませんが、結論はそうなりません。

消費カロリーだけを見れば、**食事を調整する方がはるかに効率的**です。ごはんを茶碗半分減らす方が、30分歩くより簡単に同じ効果が出ます。

一方で、運動には収支の外側の意味があります。減量中に落ちる体重のうち筋肉の割合を抑えること、体力そのもの、体型の変化。これらは食事制限だけでは得られません。

つまり、

- **体重を減らすため** → 主に食事
- **減った後の体を作るため** → 運動

という役割分担で考えると、期待と現実が合いやすくなります。「運動したから食べていい」ではなく、「運動は別の目的のためにやる」と切り分けるだけで、続けやすさが変わります。

## まとめ

- 消費カロリー ＝ メッツ × 時間 × 体重 × 1.05
- 体重70kgの速歩30分で147kcal。ごはん茶碗1杯にも届かない
- ごはん1杯を消費するには速歩で48分
- この式の値は安静時ぶんを含む総量で、個人差もある
- 体重を減らす主役は食事。運動は別の役割で効いてくる

この記事は一般的な情報の整理であり、個別の指導や診断を目的としたものではありません。体調に不安がある場合は無理に運動量を増やさず、医療機関にご相談ください。
