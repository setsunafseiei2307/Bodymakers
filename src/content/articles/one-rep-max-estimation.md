1RM（One Repetition Maximum）は、正しいフォームで1回だけ挙げられる最大重量のことです。
トレーニングの負荷設定はこの値を基準に組み立てられることが多く、
「1RMの80%で5回3セット」のような指示は、1RMが分かっていて初めて成立します。

ただし1RMを実測するには、失敗する寸前の重量を扱うことになります。
補助者やセーフティバーがない環境では現実的ではありませんし、
頻繁に測るものでもありません。そこで使われるのが、
**軽い重量で複数回挙げた記録から1RMを逆算する換算式**です。

## 換算式の考え方

どの式も「挙げられる回数が増えるほど、扱える重量は下がる」という関係を数式にしたものです。
最もよく使われる Epley の式は次の形をしています。

```
1RM = 重量 × (1 + レップ数 ÷ 30)
```

100kgを5回挙げられた場合、100 × (1 + 5/30) = 約116.7kg が推定値になります。

同じ入力に対して、式によって答えは変わります。主要な7つの式で100kg×5回を計算すると次のようになります。

| 式 | 推定1RM |
|---|---|
| Epley (1985) | 116.7 kg |
| Brzycki (1993) | 112.5 kg |
| Lander (1985) | 113.6 kg |
| Lombardi (1989) | 117.5 kg |
| O'Conner (1989) | 112.5 kg |
| Mayhew (1992) | 113.6 kg |
| Wathen (1994) | 114.7 kg |

幅はおよそ5kg、率にして4%ほどです。
当サイトの[筋力レベル診断](/strength-standards)では、この7式の平均値を推定1RMとして採用し、
式による差も併せて表示しています。特定の式だけを信頼する根拠がないためです。

## レップ数が増えるほど誤差は広がる

換算式が比較的よく当たるのは、**レップ数が少ない範囲**です。
1回に近いほど推定するまでもなく、回数が増えるほど式ごとの前提の違いが効いてきます。

100kgを12回挙げた場合で同じ計算をすると、推定値は Brzycki の144kg から
Lombardi の127.6kg まで、16kg以上の幅が出ます。率にすると12%を超えます。

このため当サイトの計算では、**1〜12回までを対象とし、それ以上のレップ数からは推定しません**。
13回以上挙げられる重量からの逆算は、実用に耐える精度が期待できないためです。

## 個人差と種目差

式による差以上に大きいのが、個人差と種目差です。

同じ「5回できる重量」でも、筋線維の構成や神経系の特性によって、
1RMとの比率は人それぞれ異なります。持久的な傾向が強い人は、
高回数をこなせる割に1RMが伸びにくく、換算式は過大に見積もりがちです。

種目による違いもあります。LeSuer らの研究では、
式ごとにベンチプレス・スクワット・デッドリフトで精度が異なることが報告されています。
単一の式ですべての種目を扱うと、種目によって系統的なずれが生じます。

## 実務上の使い方

推定1RMは、**絶対値として扱うのではなく、変化を追う指標として使う**のが現実的です。

同じ式・同じレップ数で継続して記録していれば、推定値の上下は
実際の筋力の変化をよく反映します。「先月は100kg×5回、今月は105kg×5回」であれば、
推定値の絶対精度がどうであれ、強くなったことは確かです。

また、推定値をそのまま最大挑戦の目標にするのは避けてください。
体調・睡眠・その日のコンディションによって、実際に挙がる重量は容易に5%程度変動します。
高重量に挑戦する際は、必ずセーフティバーの使用や補助者の同伴といった安全策を取ってください。

## まとめ

- 換算式は、少ないレップ数（おおむね5回以下）で最も信頼できる
- 式によって数%の差が出るため、複数の式の平均を使うのが無難
- レップ数が増えるほど誤差は急速に広がる
- 絶対値より、同じ条件で測り続けたときの**変化**を見るほうが有用
