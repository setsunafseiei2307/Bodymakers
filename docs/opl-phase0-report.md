# OpenPowerlifting 日本人データ Phase 0 実データ調査

このドキュメントは実装ドキュメントではない。**「OpenPowerliftingの日本人データが、
Bodymakersの筋力レベル判定に実用できる量・品質なのか」を実測しただけ**のレポートで、
Strength Standards本体の実装判断はここでは行わない。UI変更・機能追加・本番JSON生成は
一切行っていない。

再実行:

```

python3 scripts/opl-phase0/analyze.py      # 調査1〜9を実行し、JSONと標準出力に出す
```

### 取得経路についての注記

公式Data Serviceの案内ページ（`https://openpowerlifting.gitlab.io/opl-csv/`）はGitLab Pages
（`*.gitlab.io`サブドメイン）でホストされているが、本セッションの実行環境ではこのサブドメインへの
接続がネットワークポリシーにより`403 Forbidden`でブロックされた（`www.openpowerlifting.org` /
`data.openpowerlifting.org` も同様にブロック）。`gitlab.com`自体は疎通できたため、同じ公式
リポジトリ（`openpowerlifting/opl-csv`）の最新成功パイプラインが生成したCIジョブ成果物を
GitLab API経由で取得した。スクレイピングは行っておらず、取得先は公式リポジトリの公式CI成果物
そのものである。この経路は`scripts/opl-phase0/fetch_data.py`に実装済みで、再実行可能。

**Equipment=="Raw"についての公式仕様上の注意（想定と違う点ではなく、公式README記載の
既知の仕様）:** OpenPowerlifting公式READMEは「Equipmentは実際にその装備を使用したことを
保証する値ではない」と明記している。例としてGPC系連盟のように、Wrapsの使用が許可された
カテゴリで出場した選手は、実際には膝スリーブのみ・無装備であっても`Equipment=="Wraps"`に
分類される。裏を返せば`Equipment=="Raw"`も「無補助具カテゴリで出場した」ことを示すのみで、
個々の選手が実際に何も装備しなかったことを個別に保証するものではない。今回の日本人母集団は
Federation列がJPA/IPF中心（IPF系はRaw区分の定義が比較的厳格）のため実務上の影響は
限定的と考えられるが、仕様上の限界として明記しておく。

想定と違った点は上記以外になし。負の記録・Dots/Goodlift欠損・Sanctioned=="No"などの
異常系は主母集団候補内には実質存在しなかった。

## 想定と違った点のまとめ

1. **2006〜2011年の6年間、日本のRaw SBDデータが完全に空白**。データソース側の収録
   タイミングの問題と推測されるが、Phase 0では原因追跡していない。
2. **年齢の86%が整数年齢ではなくx.5の近似値**。実年齢2通りのうちどちらかを選ぶ必要が
   あり、単純な「Age列をそのまま使う」設計では精度が落ちる。
3. **Tested/Sanctioned/Sex/Bodyweight系フィルタがほぼ無効果**。日本のRaw SBDデータ自体が
   すでに均質（ほぼ全件Tested==Yes、Sanctioned!=No、Sex∈{M,F}、体重欠損・範囲外なし）で、
   実質的な絞り込みはEquipment==RawとEvent==SBDの2つだけで説明できる。
4. **S単独・SB・SDカテゴリが日本のRawデータに1件も存在しない**。

## Strength Standardsに使う上での重大リスク

1. **体重×年齢の交差セルは薄い**。特に重い体重帯（男性105kg超、女性76kg超）や高齢層
   （60+）で単独のセルが数人〜0人になる。体重のみ・年齢のみの1次元セルはある程度の
   厚みがあるが、2次元クロスで区切ると成立しないセルが出る。
2. **2006〜2011年の空白と2020年のコロナ落ち込みがあるため、Date下限の設定次第で
   母集団の性格（年齢構成・連盟構成）が変わりうる**。この判断はPhase 0の範囲外。
3. **年齢の86%が近似値（x.5）**。年齢帯別の基準値を作る場合、実年齢の曖昧さをどう
   扱うかの設計判断が別途必要。
4. **母集団の90.7%が単一連盟（JPA）由来、99.9%が単一系列（ParentFederation=IPF）**。
   これは「日本のパワーリフティング競技者」を代表するデータであり、**一般日本人の
   筋力分布への外挿は禁止事項どおり行っていない**し、行うべきではない。
5. **Equipment=="Raw"は無補助具の保証ではない**（8節参照）という公式仕様上の限界がある。
